System Architecture

Agent Pipeline

MARS uses a multi-agent architecture where specialized LLM agents work together to extract, classify, and summarize medical report data. Each agent has a focused responsibility.

LLM Agents
14
CNN Models
1 (YOLO)
Categories
5
🔍

Classification Agents

1 Agent
Report Page Classifier
is_report_page()

Stage 1: Classifies if a page is a structured report (lab, prescription, bill, etc.) and returns type + confidence.

2 Agent
Medical Image Confirmer
confirm_medical_image()

LLM second opinion on whether a YOLO-cropped sub-image is actually a medical scan.

📊

Data Extraction Agents

3 Agent
Tabular Data Extractor
extract_report_tabular_data()

Stage 2: Extracts tables from confirmed report pages into structured JSON (columns, rows, metadata).

4 Agent
Lab Value Deviation Analyzer
analyze_lab_value_deviations()

Flags abnormal lab values (high/low) and adds patient-friendly explanations. Text-only call.

5 Agent
Detailed Summary Extractor
extract_detailed_summary()

Generates a thorough summary of the report. Extracted first and used as context for other agents.

6 Agent
Patient & Doctor Info Extractor
extract_patient_and_doctor_info()

Extracts patient name/age/sex and doctor name/phone/email from page images.

7 Agent
Patient History Extractor
extract_patient_history_from_text()

Extracts past conditions, allergies, and previous treatments from summary text. Text-only call.

8 Agent
Report Summary Extractor
extract_report_summary()

Extracts findings, diagnosis, patient explanation, and recommendations.

9 Agent
Medications & Appointments Extractor
extract_medications_and_appointments()

Extracts prescribed meds (name/dosage/frequency/duration) and next appointment.

10 Agent
Medications & Appointments (Text)
extract_medications_and_appointments_from_text()

Cost-saving text-only alternative to the image-based medications extractor.

11 Agent
Patient & Doctor Info (Text)
extract_patient_and_doctor_info_from_text()

Cost-saving text-only alternative to the image-based patient/doctor info extractor.

🖼️

Image Agents

12 Agent
Medical Image Describer
describe_medical_image()

Generates a short caption + patient-friendly description for a medical image. Uses summary as context.

🔧

Utility Agents

13 Agent
LLM Response Cleanup
_cleanup_llm_response()

Second LLM call to extract valid JSON from a malformed first response. Fallback for parsing failures.

❓

Interactive Agents

14 Agent
Image Region Query
query_image_region()

Draws a red bounding box on a user-specified region, then asks the LLM a question about it.

⚙️

YOLO Medical Image Detector
get_bounding_boxes()
